# process-engineering-toolkit
Interactive HTML/CSS tools and templates for Business Process Engineering, process landscapes, and BPMN documentation.

## Available Templates
* **`process-landscape.html`:** An interactive visual map to structure Management, Core, and Support processes.
* **`process-fact-sheet.html`:** A structured digital datasheet for individual processes (purpose, trigger, KPIs, and RACI alignment).

## Features
* Plain HTML/CSS/JS (no frameworks or extra setup needed)
* Easy to edit and customize
* Runs directly in any web browser

## How to use
1. Download or clone the repository.
2. Open any `.html` file directly in your browser.
3. Edit the code to match your own process structure.
